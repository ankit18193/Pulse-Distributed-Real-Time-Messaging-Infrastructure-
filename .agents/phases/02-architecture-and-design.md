# Workflow 02: Architecture and Design

This workflow turns product requirements into concrete engineering specs and design systems.

## Available Skills
- `/design-consultation`: Interactively defines typography, colors, component tokens, layout grids, and accessibility.
- `/spec`: Builds an executable 5-phase engineering specification from vague intent.
- `/diagram`: Generates ASCII, Mermaid, and architecture diagrams.

## How to Run in Antigravity
1. Run `/spec` to draft a formal specification with clear verification criteria.
2. Run `/design-consultation` when designing UI or client-facing interfaces.
3. Keep architecture diagrams synchronized with code in plans and docstrings.
