# Engineering Retrospective Workflow

Analyze engineering velocity, shipping cadence, commit streaks, and process bottlenecks.

## Overview
Reflects on team execution: measures cadence, highlights wins, and identifies friction areas.

## Protocol & Guidelines
1. Refer to the full skill specification at [SKILL.md](file:///.agents/skills/retro/SKILL.md).
2. Inspect git commit logs, merged PRs, and commit timestamps over the target period.
3. Measure:
   - Shipping frequency and streaks
   - Commit size distribution and bisectability
   - Context switching and parallel work streams
4. Highlight major milestones shipped.
5. Recommend 1-2 concrete process improvements for the next cycle.
