# Engineering Specification Author Workflow

Transform feature requests into a formal, phased 5-part engineering specification.

## Overview
Creates unambiguous, executable specifications ready for implementation.

## Protocol & Guidelines
1. Refer to the full skill specification at [SKILL.md](file:///.agents/skills/spec/SKILL.md).
2. Structure specification into 5 parts:
   - **Part 1**: Problem statement, background, and non-goals.
   - **Part 2**: User stories and acceptance criteria.
   - **Part 3**: System architecture, data models, and API contracts.
   - **Part 4**: Edge cases, failure modes, and security posture.
   - **Part 5**: Phased rollout and verification plan.
3. Save specification artifact and obtain approval before coding.
