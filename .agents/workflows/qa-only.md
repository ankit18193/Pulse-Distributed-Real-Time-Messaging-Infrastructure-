# Report-Only QA Audit Workflow

Audit a web application and generate a comprehensive QA defect report without making code changes.

## Overview
Performs read-only browser exploration and files prioritized bug reports.

## Protocol & Guidelines
1. Refer to the full skill specification at [SKILL.md](file:///.agents/skills/qa-only/SKILL.md).
2. Drive application user flows using `browser_subagent`.
3. Document all functional, layout, accessibility, and performance anomalies.
4. Categorize by severity: Critical, Major, Minor, Cosmetic.
5. Produce structured audit report with reproduction steps and evidence.
