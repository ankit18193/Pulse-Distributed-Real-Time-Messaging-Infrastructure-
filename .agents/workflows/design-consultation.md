# Design System Consultation Workflow

Architect a complete, production-grade design system from scratch.

## Overview
Generates harmonious color palettes, typographic scales, spacing units, and component tokens.

## Protocol & Guidelines
1. Refer to the full skill specification at [SKILL.md](file:///.agents/skills/design-consultation/SKILL.md).
2. Define design foundation:
   - **Color System**: Primary, neutral, surface, accent, and semantic status colors.
   - **Typography**: Font family, modular scale, weights, and line heights.
   - **Spatial Rhythm**: 4px/8px grid system, radii, elevation shadows.
3. Generate reusable CSS custom properties / design tokens.
4. Verify accessibility and contrast ratios (WCAG AA compliance).
