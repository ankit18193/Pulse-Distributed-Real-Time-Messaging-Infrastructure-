# Diataxis Documentation Generator Workflow

Generate structured documentation according to the Diataxis documentation framework.

## Overview
Writes clear, targeted technical documentation mapped to 4 distinct modes.

## Protocol & Guidelines
1. Refer to the full skill specification at [SKILL.md](file:///.agents/skills/document-generate/SKILL.md).
2. Select target Diataxis mode:
   - **Tutorial**: Learning-oriented, step-by-step for beginners.
   - **How-To Guide**: Problem-oriented, focused steps to solve a specific task.
   - **Reference**: Information-oriented, authoritative API/schema descriptions.
   - **Explanation**: Understanding-oriented, architectural discussions and design rationale.
3. Extract accurate contracts directly from code.
4. Format with clean GitHub markdown and verified code examples.
