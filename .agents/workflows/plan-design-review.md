# Design Plan Review Workflow

Execute design director review across visual aesthetics, interaction states, and information architecture.

## Overview
Evaluates user experience across the 10 design dimensions to ensure premium visual and interaction quality.

## Protocol & Guidelines
1. Refer to the full skill specification at [SKILL.md](file:///.agents/skills/plan-design-review/SKILL.md).
2. Score proposed UI/UX across: Typography, Color harmony, Spacing rhythm, Micro-interactions, Loading/Empty/Error states, and Responsive behavior.
3. Define what a "10/10" looks like for each dimension.
4. Align with design tokens and tokens in [design-consultation](file:///.agents/skills/design-consultation/SKILL.md).
5. Update the implementation plan with exact layout, token, and state specifications.
