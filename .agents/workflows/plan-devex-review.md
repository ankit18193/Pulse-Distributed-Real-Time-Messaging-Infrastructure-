# Developer Experience (DevEx) Review Workflow

Audit and optimize the developer onboarding, API ergonomics, and developer journey.

## Overview
Minimizes Time-to-Hello-World (TTHW), removes cognitive friction, and designs delightful developer APIs.

## Protocol & Guidelines
1. Refer to the full skill specification at [SKILL.md](file:///.agents/skills/plan-devex-review/SKILL.md).
2. Audit the developer journey step-by-step: discovery, installation, configuration, first run, error diagnostics.
3. Compare against the DX Hall of Fame patterns in [.agents/skills/plan-devex-review/dx-hall-of-fame.md](file:///.agents/skills/plan-devex-review/dx-hall-of-fame.md).
4. Identify and eliminate friction points (unnecessary flags, silent errors, vague stack traces).
5. Update the implementation plan with DX improvements.
