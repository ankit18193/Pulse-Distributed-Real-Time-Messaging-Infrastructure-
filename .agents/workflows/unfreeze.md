# Safety Boundary Release (Unfreeze) Workflow

Release active directory edit restrictions and restore normal editing permissions.

## Overview
Clears active directory locks set by `/freeze` or `/guard`.

## Protocol & Guidelines
1. Refer to the full skill specification at [SKILL.md](file:///.agents/skills/unfreeze/SKILL.md).
2. Verify active tasks in the previously locked directory are complete.
3. Clear restriction boundaries.
4. Confirm workspace is returned to standard unrestricted mode.
