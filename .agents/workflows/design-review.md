# Live Visual Design Review Workflow

Audit a live application UI via browser inspection and apply atomic fix commits.

## Overview
Inspects running frontend interfaces for visual polish, alignment, typography, and responsive flaws.

## Protocol & Guidelines
1. Refer to the full skill specification at [SKILL.md](file:///.agents/skills/design-review/SKILL.md).
2. Navigate to target URL using `browser_subagent` or `read_url_content`.
3. Audit visual dimensions: Spacing alignment, color consistency, contrast, typography, transitions.
4. Apply atomic commits for each visual polish fix.
5. Re-verify in browser and capture screenshot/video evidence.
