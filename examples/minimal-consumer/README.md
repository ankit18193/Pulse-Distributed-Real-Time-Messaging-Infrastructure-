# Minimal Pulse Consumer Reference App

This directory demonstrates how an external Node.js application consumes `@ankit18193/pulse` as a published NPM package.

---

## 1. Quick Start

### Start the Pulse Server
```bash
node server.js
```
The server will start on port `8888` (or the port specified by `PORT` environment variable).

### Run the Client
In a second terminal window:
```bash
node client.js alice
```

You should see:
1. Client connects via native WebSocket.
2. Authenticates with HMAC token generated by `Authenticator`.
3. Joins the `engineering-lobby` room.
4. Broadcasts a room message with delivery acknowledgment.
5. Receives `DELIVERY_ACK` confirmation.

---

## 2. Server Implementation (`server.js`)
```javascript
import { PulseServer } from '@ankit18193/pulse';

const server = new PulseServer({
  port: 8888,
  authSecret: process.env.AUTH_SECRET || 'pulse-dev-secret-key-32chars-min'
});

await server.start();
```

---

## 3. Production Configuration
To enable Redis clustering in production:
```bash
PORT=8080 \
NODE_ENV=production \
AUTH_SECRET="your-strong-production-secret-at-least-32-chars-long" \
REDIS_ENABLED=true \
REDIS_URL="redis://your-redis-cluster:6379" \
node server.js
```
