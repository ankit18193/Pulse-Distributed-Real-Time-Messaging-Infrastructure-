## Affected Pages / Routes

- `/proxy/api/*` — HTTP reverse proxy route to upstream servers; tests that RouteX intercepts, applies rate-limiting, and forwards via Undici.
- `/proxy/ws` — WebSocket reverse proxy route; tests that RouteX negotiates RFC 6455 upgrade and pipes full-duplex frames to upstream target.
- `/healthz` & `/livez` — Native Pulse health endpoints; tests that unmatched routes fall through cleanly to Pulse HTTP handler without header double-writes.
- `/metrics` — Native Pulse Prometheus endpoint; tests that metrics serialization succeeds without interference.
- `/` & `/ws` — Native Pulse room WebSocket endpoints; tests that authenticated clients receive `SYS_CONNECT_ACK` and join distributed rooms.

---

## Key Interactions to Verify

1. **HTTP Proxy Forwarding**:
   - `GET /proxy/api/hello` returns HTTP 200 from mock upstream.
   - Request headers sanitized (hop-by-hop removed, `x-request-id` assigned).
2. **HTTP Native Fall-Through**:
   - `GET /healthz` returns HTTP 200 with Pulse health status payload.
   - `GET /metrics` returns HTTP 200 with Prometheus text output.
   - `GET /nonexistent` returns HTTP 404 from Pulse without `ERR_HTTP_HEADERS_SENT`.
3. **WebSocket Tunneling vs Native Bypass**:
   - Connect to `/proxy/ws` -> establishes full-duplex tunnel to mock upstream WebSocket server.
   - Connect to `/` with valid JWT -> connects to Pulse room engine, receives `SYS_CONNECT_ACK`.
   - Connect to `/` with invalid/missing JWT -> receives HTTP 401 Unauthorized from Pulse.
4. **Interleaved Upgrade Concurrency**:
   - 50 concurrent upgrades firing simultaneously (25 to `/proxy/ws`, 25 to `/`).
   - Verifies 100% success rate with zero socket stream corruption.

---

## Edge Cases & Failure Modes

1. **Upstream Unavailable**:
   - Upstream server offline -> RouteX returns 502/504 Bad Gateway / Gateway Timeout.
   - Pulse process remains healthy and serves `/healthz`.
2. **Rate Limit Exhaustion**:
   - Token bucket depleted -> RouteX returns 429 Too Many Requests; Pulse native routes unaffected.
3. **Graceful Draining & Shutdown**:
   - Calling `pulseServer.stop()` triggers `routexGateway.close()`.
   - Active proxy tunnels drained cleanly; active Pulse rooms receive `SYS_SHUTDOWN`.
   - Port 8080 releases without open socket leaks.

---

## Critical Paths

- **Single-Port Invariant Flow**: Single Node.js `http.Server` handles both external edge proxy traffic and internal distributed pub/sub WebSockets with zero container sidecars.
