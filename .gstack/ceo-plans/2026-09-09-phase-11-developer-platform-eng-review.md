## 2. Review Decisions Matrix

| Area | Decision | Trade-offs & Rationale |
| :--- | :--- | :--- |
| **CLI Runner** | Move CLI runner to [`src/bin/pulse-server.ts`](file:///d:/Pulse/Pulse-Distributed-Real-Time-Messaging-Infrastructure-/src/bin/pulse-server.ts) with `pulse-server` binary name. | Eliminates process-level side-effects from importing the library. Keeps server command clear and distinct. |
| **Module Format** | Pure ESM (`"type": "module"`), `target: ES2022`, `NodeNext` resolution. | Matches Node.js >=20 standards and sibling `@ankit18193/routex-gateway`. Zero transpiler bundling friction. |
| **Export Map** | Root `"."` plus subpaths `"./config"`, `"./types"`, `"./metrics"`. | Maximum consumer ergonomics: allows lightweight type and schema imports without loading the full WebSocket server. |
| **Internal Hiding** | Strict encapsulation in [`src/index.ts`](file:///d:/Pulse/Pulse-Distributed-Real-Time-Messaging-Infrastructure-/src/index.ts). | Hides `ConnectionManager`, `MessageDispatcher`, `PresenceManager`, `IdempotencyManager`, and Lua scripts from external consumers. |
| **Consumer Test** | Permanent runnable reference example in `examples/minimal-consumer/` validated by automated `npm pack` test. | Serves as both checked-in developer tutorial and automated black-box test harness. |
| **Sourcemaps** | Include `.js.map` sourcemaps in `dist/`. | Delivers actionable stack traces during consumer debugging with negligible disk footprint. |
