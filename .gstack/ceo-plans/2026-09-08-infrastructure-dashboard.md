## Vision

### 10x Check
Instead of a passive telemetry reader that displays zeroes until an external terminal load test is launched, Pulse Mission Control is an interactive infrastructure control cockpit. A user can open the dashboard, click "Generate Traffic Burst", and watch live message ingest and egress counters tick at 60 FPS while the rolling SVG waveform chart displays real fan-out multiplication and the Node.js event-loop lag gauge registers sub-millisecond thread stress.

### Platonic Ideal
The platonic ideal of an infrastructure dashboard is not a chat clone; it is a developer's microscope into a distributed real-time engine. Every single widget represents a real metric from `PulseMetricsRegistry`, RouteX Gateway, or Redis Pub/Sub. The UI looks like an Obsidian space-grade mission control console with zero vanity bloat.

## Accepted Scope (added to this plan)
- Vite + React + TypeScript SPA in `dashboard/` with Obsidian Dark Theme and zero-dependency SVG waveform charts.
- 4 primary views: Cockpit Overview, Rooms & Connections Explorer, RouteX Gateway Inspector, Traffic Sandbox.
- 1-Click Traffic Generator inside Traffic Sandbox (bursts client-side WebSockets from browser to generate live msg/s load).
- Raw Frame Inspector in Sandbox with 1-click JSON copy and inbound/outbound filter.
- Consolidated `GET /api/stats` endpoint and CORS enablement in `PulseServer.ts`.
